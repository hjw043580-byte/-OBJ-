# -OBJ-# Unity OBJ 3D模型浏览器
课程实验项目：运行时解析外部OBJ三维模型
功能：
1. C#代码读取OBJ文本文件，解析顶点、三角面
2. 内存动态生成Mesh，创建3D模型
3. 鼠标交互：左键旋转、滚轮缩放、右键平移浏览模型
4. 可读取原始顶点数据，方便后续网格开发

# -Curve-# Unity 
功能说明
本程序使用 Unity 实现参数曲线的建模与交互，支持：
- Bézier 曲线
- Hermite 曲线
- Catmull-Rom 曲线
- B-Spline 曲线
- 控制点的添加、拖动和删除
- 曲线整体平移、旋转和缩放
- Hermite、Catmull-Rom 与 Bézier 之间的转换
操作说明
- 鼠标左键点击空白处：添加控制点
- 鼠标左键拖动控制点：修改曲线形状
- 鼠标右键点击控制点：删除控制点
- 数字键 1：切换到 Bézier
- 数字键 2：切换到 Hermite
- 数字键 3：切换到 Catmull-Rom
- 数字键 4：切换到 B-Spline
- W/A/S/D：平移曲线
- Q/E：旋转曲线
- Z/X：缩小或放大曲线
注意事项
- 项目需要安装并启用 Unity Input System。
